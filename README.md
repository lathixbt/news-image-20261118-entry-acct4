One picture summing up Wednesday 18 November 2026: 36 stories, 6 continents, on a single page.

A clean, airy newspaper front page — a centered serif masthead, a slim colour region bar, a "THE DAY IN NUMBERS" strip, 9 illustrated panels in a 3×3 grid, 27 briefs in 3 columns, and a full-width world map with every story pinned and numbered.

## How it works

`main.py` copies the finished `entry.png` to the output path (default `./entry.png`). It uses only the Python standard library.

```sh
python3 main.py [output-path]
```

## Contents

- `entry.png` — the finished 1024×1024 infographic (36 stories)
- `main.py` — stdlib-only copier entrypoint

All text in the image is drawn programmatically; every story happened, or was first reported, on Wednesday 18 November 2026. Claims are attributed. Original drawings.
